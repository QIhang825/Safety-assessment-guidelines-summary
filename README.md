# Safety assessment guidelines summary

劳务分包商与作业人员 **安全积分考核** 交互原型，用于对照安全考核办法梳理项目侧、公司侧的计分、预警、停工培训、清退和黑名单流程。

演示场景默认落在 **雄忻高铁 3 标**。数据全部写在浏览器本地脚本里，打开即可点，不接后端。

## 考核原则

- 对象：劳务分包商，以及完成三级教育后的作业人员。
- 进场赋分 100，从进场累计到退场，**不按月清零**。
- 分包商按项目分别记账；公司层看跨项目算术平均，黑名单标识不受平均分影响。
- 人员违章会按规则联动扣分包商分。
- 人员与分包商基础档案来自劳务教育 / 供应商库，本模块只读同步，不办进场登记和三级教育。
- 退场冻结后不再参与考核；重新进场后恢复，历史分和流水保留。

当前原型 **不包含**：集团汇总、发卡、平安班组、欠薪 / 门禁、开工条件。检查隐患页只查看已入分详情，不在本模块做源头排查。

## 本地预览

需要本机已安装 Python 3。在仓库根目录执行：

```bash
cd subcontractor-points-prototype
python -m http.server 8765
```

然后打开：

- Web 管理端：http://localhost:8765/index.html
- 移动端示意：http://localhost:8765/app.html
- 产品流程图：http://localhost:8765/产品流程图.html

也可以直接用浏览器打开对应 HTML。右上角角色切换可分别看项目安全员、项目领导小组、工程公司安监、安委会的菜单和权限。

## Web 端功能

右上角切换角色后，可见菜单会跟着变。

| 页面 | 说明 |
| --- | --- |
| 项目看板 | KPI、分值分布、违规人数折线、人员 / 分包商排名；公司角色可见「在建项目数量」并可下穿 |
| 作业人员积分 | 累计计分列表；点姓名看教育档案，操作列看明细、记分和处置 |
| 检查隐患 | 查看已映射入分的隐患详情 |
| 停工培训确认 | 对照劳务教育同步的成绩，确认是否复岗加分；第二次停工培训不可复岗加分 |
| 分包商积分 | 点名称看供应商档案；勾选后可导出积分列表和明细；领导小组可直接列入黑名单 |
| 月度考核 | 每月节点快照，不重置累计分 |
| 进场账户 | 从劳务教育同步账户；冻结 / 解冻考核参与 |
| 规则配置 | 预警分级、加分、月度节点、联动扣分、违章库、标准库、灰黄红牌参照、隐患映射 |
| 公司汇总 | 工程公司按项目平均分汇总并下穿 |
| 黑名单库 | 人员 / 分包商黑名单查询与导出 |

默认预警线（可在规则配置中改）：

| 阈值 | 含义 |
| --- | --- |
| 90 分以下 | 重点管控 |
| 80 分以下 | 停工培训 |
| 70 分以下 | 清退，并按规则进入人员黑名单 |
| 二次停工培训 | 直接列入人员黑名单 |

人员联动扣分包商的默认值：进入黑名单 1 分、停工培训 0.5 分、一般违章 0.1 分。月度快照默认每月 25 日。

## 角色

| 角色 | 视角 |
| --- | --- |
| 项目安全员 | 默认角色，只看本项目；可记分、确认停工培训 |
| 项目领导小组 | 本项目审批类动作（如列入分包商黑名单） |
| 工程公司安监 | 全部项目汇总、下穿、公司侧黑名单 |
| 安委会 | 公司层查看 |
